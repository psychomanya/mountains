# 🏔️ Веб-приложение «Горы и вершины»

Интерактивное образовательное веб-приложение для школьников по географии с методикой интервального повторения (**SM-2**).

Приложение помогает легко и наглядно выучить расположение главных горных массивов планеты, ключевых вершин и терминологию по теме «Горы и вулканы».

---

## 🌟 Возможности приложения

1. **🗺️ Карта гор и вершин (Тренажер поиска):**
   * **14 горных систем:** Аппалачи, Анды, Пиренеи, Апеннины, Альпы, Карпаты, Урал, Кавказ, Атлас, Тянь-Шань, Алтай, Гиндукуш, Памир, Гималаи.
   * **5 великих вершин с обязательными фактами:**
     * **Аконкагуа** — *высшая точка Южной Америки* (6961 м)
     * **Килиманджаро** — *высшая точка Африки* (5895 м)
     * **Синай** — *священная гора христиан, иудеев и мусульман* (2285 м)
     * **Эльбрус** — *высшая точка России и Европы* (5642 м)
     * **Эверест** — *высшая точка Азии и всей планеты* (8848 м)
   * Интерактивный клик по физической карте мира без подсказок с мгновенной подсветкой.

2. **🌋 Термины и вулканы:**
   * **Интерактивная векторная схема горы:** сопоставление меток (вершина/пик, подножие, хребет, перевал, ледник, долина).
   * **Виды склонов:** наглядное различие понятий: *пологий*, *крутой* и *отвесный (вертикальный обрыв 90°)*.
   * **Интерактивный разрез вулкана:** кратер (воронка), жерло (канал), магматический очаг.
   * **Ключевое отличие: Мантия против Лавы:**
     * *Мантия* — толща Земли в недрах под корой, где зарождается магма под колоссальным давлением.
     * *Лава* — магма, излившаяся на земную поверхность и потерявшая газы на открытом воздухе.

3. **🧠 Научный алгоритм интервального повторения (SM-2):**
   * Независимые расписания повторения для карты и терминов.
   * Оценки: *«Снова» (10 мин)*, *«Трудно» (1 дн)*, *«Хорошо» (4 дн)*, *«Легко» (6+ дн)*.
   * Весь прогресс сохраняется в браузере (`localStorage`) — доступ без логинов и паролей.

4. **📖 Справочник-Атлас:**
   * Свободный просмотр всей теории, координат, фактов и терминов с поиском и фильтрами.

5. **🏅 Дневник экспедиции:**
   * Ранги исследователя (от «Новичка» до «Мастера горных вершин»), бейджи достижений и статистика.

6. **🎵 Звуки экспедиции:**
   * Встроенный синтез приятных звуков через Web Audio API (без внешних тяжелых файлов, с возможностью выключения).

7. **🇷🇺 Доступность в РФ:**
   * Все шрифты, иконки и код упакованы локально.
   * Надежные тайлы карты (CartoDB, ESRI Topo, OpenStreetMap) работают быстро и стабильно в РФ без VPN.

## 🚀 Как запустить на компьютере

Для работы нужен установленный [Node.js](https://nodejs.org/).

1. Откройте папку проекта в терминале:
   ```bash
   npm install
   ```

2. Запустите локальный сервер:
   ```bash
   npm run dev
   ```

3. Откройте ссылку в браузере (обычно `http://localhost:5173`).

## 🌐 Как бесплатно выложить в интернет (на GitHub Pages)

Проект полностью настроен для автоматической публикации на **GitHub Pages** (работает в РФ без VPN):

1. Создайте бесплатный репозиторий на [GitHub.com](https://github.com/) (например, с именем `mountains-app`).
2. В терминале в папке проекта выполните:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Mountains and Peaks app"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/mountains-app.git
   git push -u origin main
   ```
3. В настройках вашего репозитория на GitHub перейдите в **Settings** ➔ **Pages**:
   * В пункте **Source** выберите **GitHub Actions**.
4. GitHub автоматически запустит файл `.github/workflows/deploy.yml` и через 1 минуту выдаст готовую ссылку для учеников: `https://ВАШ_ЛОГИН.github.io/mountains-app/`!
